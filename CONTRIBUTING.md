# Contributing

Bombarie is a tool Pop-Up City built for itself. Fixes and small improvements are welcome; for anything bigger, open an issue first, because the app is kept deliberately small.

- Read `AGENTS.md` for the rules of the code: Tailwind classes only, no comments in code, no backwards compatibility, a test for logic.
- `pnpm test`, `pnpm typecheck` and `pnpm build` must pass.
- One change per pull request, with the reason in the description.
